AkariNet Actions

Let StarSeries models call tools with <action> / <action_input> tags. Runs as the akari-actions automaton (on by default).

Enable Actions

When off, action tags in replies are ignored.

Strict: confirm all tools.
General: auto-run safe tools (time, search, weather…); confirm eval_js, present_html, bash, garage, etc.
Unlimited: Akari can run any registered tool without asking.

After this many tool→model loops, Actions stops until you send a message (default 5).

Strip action tags from speech path

Tools still run; tags are mainly for the model protocol.

Built-in tools include: get_time, get_date, get_weather, web_search, calculator, open_app, set_reminder, present_html, eval_js, tool_search, and more. List them in chat with a model call to tool_search.
